# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## 1.1.1 — 2026-09-15

- Настройки JPEG объединены с форматом HTML в один компактный блок.
- Режимы изображений становятся недоступны при выбранном Markdown.
- Экран настроек полностью помещается в окно плагина без прокрутки.

## 1.1.0 — 2026-09-15

- Добавлены режимы HTML-изображений: встроенные Base64, отдельные JPEG в ZIP и экспорт без картинок.
- Выбранный режим изображений сохраняется в настройках Pixso.
- Экспорт ограничен выбранными верхнеуровневыми фреймами — прямыми детьми страницы; вложенные фреймы больше не могут стать отдельными строками.
- Логотип встроен непосредственно в исходный UI, поэтому он работает и при загрузке `src/manifest.json` через null-origin iframe Pixso.
- Восстановлен точный SVG иконки настроек из исходного плагина.

## 1.0.0 — 2026-09-15

- Полностью заменён прежний MCP Connect runtime на автономный Pixso to Spec exporter.
- Добавлены Markdown и HTML форматы.
- Добавлены прямые ссылки на выбранные фреймы.
- Добавлены JPEG-превью для HTML.
- Добавлен импорт содержимого слоя `description`.
- Сохранены фирменная иконка, размер окна и light/dark режим.
- Добавлены сборка, проверки, тесты и базовая документация репозитория.
