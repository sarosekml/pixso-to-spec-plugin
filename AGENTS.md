# AGENTS.md

Правила разработки `pixso-to-spec-plugin`.

## Граница продукта

- Плагин автономен и не зависит от MCP-сервера, внешнего API или CDN.
- Исходники находятся в `src/pixso-to-spec-plugin/`.
- Пользовательская сборка находится в `dist/pixso-to-spec/` и создаётся только через `npm run build`.
- `code.js` выполняется в sandbox Pixso и не должен обращаться к DOM, `window`, `Blob`, `URL` или сетевым API.
- `ui.html` выполняется в iframe и не должен обращаться к глобальному `pixso` напрямую.
- Обмен между слоями идёт только через `pixso.ui.postMessage` и `window.parent.postMessage`.

## Функциональный контракт

- Экспортируются только выбранные верхнеуровневые узлы типа `FRAME`, у которых `parent.type === "PAGE"`; вложенные фреймы и остальные выбранные узлы игнорируются.
- Markdown содержит три колонки и никогда не запускает `exportAsync`.
- HTML содержит те же три колонки. Режим изображений `embedded` добавляет JPEG как Base64 data URI, `separate` создаёт ZIP с `index.html` и `images/*.jpg`, `none` оставляет во второй колонке только ссылку.
- Описание — `characters` первого вложенного `TEXT`-узла с именем `description` без учёта регистра.
- Отсутствующее описание представляется пустой строкой.
- Ссылка фрейма содержит текущий `pixso.fileKey`, `page-id` и `item-id`.
- Настройки `format`, `imageMode` и `theme` хранятся только в `pixso.clientStorage`.

## Pixso runtime

- Не разносить и не переименовывать соседние литеральные вызовы `pixso.showUI(__html__, ...)` и `pixso.ui.onmessage = function (...)`: runtime Pixso может определять канал по исходному коду.
- Для JPEG использовать `frame.exportAsync({ format: "JPG", constraint: { type: "SCALE", value: 1 } })`.
- Большие бинарные данные кодировать без `String.fromCharCode.apply` на всём массиве; fallback обязан работать чанками и отдавать event loop управление.
- Новые пользовательские настройки нормализовать перед записью.

## UI

- Сохранять размер окна 350×650, фирменную иконку, основной визуальный язык и переключение light/dark.
- Фирменный PNG должен оставаться встроенным в `ui.html` как data URI: исходный manifest тоже загружается в null-origin iframe и не может полагаться на относительный URL картинки.
- Иконки действий переносить из исходного плагина без разбиения составного SVG path: разбиение меняет правила заливки и может превратить outline в сплошную фигуру.
- Не добавлять внешние шрифты, скрипты, изображения или запросы.
- Любые данные Pixso экранировать перед вставкой в HTML или Markdown.
- Один клик по `Export spec` должен приводить к одному локальному скачиванию.

## Проверка перед коммитом

```bash
npm run check
```

При изменении формата сообщений между sandbox и UI обновлять тесты и `docs/architecture.md`. Не редактировать `dist/` вручную — пересобирать.
