# Contributing

1. Создайте рабочую ветку.
2. Внесите изменения только в `src/`, `scripts/`, `tests/` или документацию.
3. Запустите `npm run check`.
4. Если изменились runtime-файлы, добавьте пересобранный `dist/pixso-to-spec`.
5. Опишите пользовательский эффект изменения в pull request.

Изменения, добавляющие сетевые зависимости или отправку данных документа наружу, должны сопровождаться отдельным privacy/security review.
